# Диагност «Волны»

Проверяет сайт и собирает отчёт: почему тормозит, какие есть ошибки, почему повторяется музыка.

**Запуск (Windows, PowerShell):**

```
tools\doctor\doctor.ps1            # полная проверка домашнего сервера, в конце откроется отчёт
tools\doctor\doctor.ps1 --quick    # быстрее: меньше браузеров и треков
tools\doctor\doctor.ps1 --mood Энергия --genres "Рок,Инди-рок" --tracks 40
tools\doctor\doctor.ps1 --url https://dro0ne.github.io/wave-music-app/ --no-field
tools\doctor\doctor.ps1 --no-lab --days 3   # только отчёты с телефонов за 3 дня
```

В первый раз скрипт сам поставит окружение (Python-пакет `playwright` и браузеры, около 400 МБ) в `tools/doctor`.

**Что проверяется**

| Раздел | Как |
|---|---|
| Загрузка и ошибки | iPhone (Safari/WebKit), Android (Chrome), компьютер (Firefox, Chrome): время загрузки, ошибки JS, упавшие запросы, вёрстка шире экрана |
| Плавность прокрутки | телефон, видеокарта ПК, процессор замедлен в 4 раза |
| Переключение треков | то же; зависания, время до нового трека и функции, которые тормозят |
| Подбор музыки | прогон волны: повторы, исполнитель подряд, мимо жанра, подкасты и минусовки, незапустившиеся треки и почему повторяется |
| Реальные устройства | отчёты, которые телефоны присылают на сервер (`telemetry.js`): зависания, FPS, ожидание трека, ошибки, реальные повторы |

Отчёты с устройств сайт отправляет только на сервере и только если в профиле включено «Отчёты о работе».
Читать их можно лишь по SSH (ключ `~/.ssh/vadm_wave`), наружу они не выставлены. Хранятся 30 дней.

Отчёты складываются в `tools/doctor/reports/` (HTML для чтения и JSON с сырыми данными).
