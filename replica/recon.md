# Карта разведки: Dotify (веб + десктоп + Android)

Срез: плеер и оформление, тексты песен, звук (эквалайзер и эффекты), библиотека и импорт.
Для: «Волна» (wave-music-app). Берём у Dotify UX и функции. Музыка остаётся из легальных
источников: Audius и другие открытые API, файлы пользователя, официальные встраиваемые плееры.
Дата: 2026-10-26

## Ключевой сценарий

Найти трек или вставить ссылку на плейлист, слушать в красивом плеере с текстами и
настройкой звука, собрать свою библиотеку.

У Dotify всё держится на том, что он проигрывает каталоги Spotify, Яндекса, VK и YouTube через
свой прокси. Это мы не клонируем (см. «Вне рамок»). У «Волны» ключевой сценарий остаётся своим:
поток по настроению и жанру из легальных источников.

## Сценарии

```

    S02 поиск -> ввод (подсказка или Tab) -> S02 результаты -> тап по треку -> S05 мини-плеер играет
    клики на счастливом пути: 3 (поиск, ввод, тап)

    медленная сеть
```

```

    S05 мини-плеер -> S03/S04 полный плеер -> лайк / в плейлист / похожие
    клики: 1
    крайние случаи: длинное название; очередь пуста -> «Похожие» заполняет её; горизонтальный экран
```

```

    S03/S04 -> «T» -> S06 -> (стиль, размер, сдвиг)
    клики: 2

    смена трека при открытом тексте
```

```
F04 Настроить звук
    S03/S04 -> эквалайзер -> S07 -> пресет или полосы -> сохраняется

```
F05 Импортировать плейлист по ссылке

F06 Собрать свой плейлист
    S11 -> «+» -> создать -> S12 -> добавить из поиска или плеера (кнопка «+» на обложке) -> порядок

```
F07 Слушать офлайн и свои файлы
    S11 -> «Загруженные» / локальные файлы -> выбрать папку или файлы -> играет без сети
    клики: 3
    крайние случаи: нет сети; неподдерживаемый формат; теги и обложки в файлах; лимит кэша

F08 Сменить оформление
    S15 -> Внешний вид -> тема / акцент / цвет от обложки / раскладка плеера / фон
    клики: 3
    крайние случаи: светлая тема с акцентом; акцент по обложке без CORS

```
F09 Уснуть под музыку
    S04 -> луна -> S09 -> 30 мин -> плавное затухание, пауза

## Источники музыки (решение 2026-10-26)

Цель: вся музыка в одном плеере для личного пользования, без обхода чужих сервисов. У
пользователя есть Spotify Premium и Яндекс Плюс. Для каждого трека «Волна» по названию,
артисту и длительности выбирает первый доступный источник и запоминает найденное:

| # | источник | как | эквалайзер / эффекты | заметки |
| --- | --- | --- | --- | --- |
| 1 | свои файлы | File System Access API / выбор файлов | да | всё работает офлайн |
| 2 | Audius (и другие открытые каталоги) | уже есть | да | |
| 3 | Spotify | Web Playback SDK + Web API, вход через OAuth PKCE (без сервера) | нет | основной каталог; нужен Client ID приложения в Spotify Developer; SDK требует Widevine — в WebView2 (Tauri) и Android WebView проверить, запасной вариант: Spotify Connect (управлять официальным приложением) |
| 4 | YouTube | IFrame Player API, поиск через Data API v3 | нет | запасной для того, чего нет в Spotify; ключ ограничить доменом; ~100 поисков в день, поэтому результаты кэшируются |

Яндекс Плюс: официального плеера для сторонних сайтов нет. Яндекс остаётся источником вкуса и
плейлистов (импорт по ссылке уже работает), треки играют через Spotify или YouTube. Проверить
официальный iframe-виджет Яндекса: если он играет целые треки для залогиненного подписчика,
его можно добавить источником 3.5.

## Вне рамок (нельзя или не стоит клонировать)

- **Воспроизведение и скачивание каталогов Spotify, Яндекс Музыки, VK, YouTube, Deezer, SoundCloud
  через свой прокси.** Это ядро Dotify, и оно нарушает условия этих сервисов и права на музыку
  (у Spotify это ещё и обход защиты). Прокси этого не меняет. Решение для «Волны» — в разделе
  «Источники музыки»: свои файлы, Audius, официальные плееры Spotify и YouTube.
- **Скачивание треков в MP3/FLAC из этих сервисов.** Та же причина. Офлайн можно только для
  того, что разрешено: свои файлы и кэш треков, лицензия которых позволяет загрузку.
- **Встроенный прокси и смена доменов против блокировок.**
- **Распознавание трека по звуку (как Shazam).** Легальные API есть (ACRCloud, AudD), но они
  платные (бесплатно только пробный период или маленький лимит) и требуют сервер для ключа.
  Отложено.
- **Их соцсеть и база пользователей.** Друзья, комнаты, топ слушателей, чарты на их данных.
  Механику можно построить, но аудитория начинается с нуля. Кроме того, это вне выбранного среза.
- **Их код, дизайн, логотип, иллюстрации (`/artwork`), тексты интерфейса.** Условия прямо
  называют их собственностью Dotify. Пишем своё.
- **Тексты песен из закрытых баз (Musixmatch и т.п.) без лицензии.** Для синхронных текстов
  есть LRCLIB (открытый, без ключа). Показывать тексты можно, хранить и раздавать массово — нет.

## Размер

Экранов 17 (в срезе 15), сценариев 9, сущностей 11.

Сложные места:
1. **Web Audio с треками с других доменов.** Эквалайзер, реверб и 8D работают только при CORS
   у источника. Audius отдаёт CORS, остальное нужно проверить или проксировать через свой сервер.
2. **Синхронные тексты.** Поиск текста по названию и длительности (LRCLIB), сопоставление,
   подсветка по словам, ручной сдвиг.
3. **Три платформы из одной кодовой базы.** Веб → PWA, десктоп через Tauri, Android через
   Capacitor или TWA. Фоновое воспроизведение на Android и локальные файлы на каждой платформе
   устроены по-разному.

Также: импорт плейлистов по ссылке нужно расширить с вкуса до настоящих плейлистов (с
сопоставлением треков на легальных источниках); синхронизация библиотеки между устройствами;
цвет от обложки.

Размер: **L** (квартал) на все три платформы. Только веб: **M** (несколько недель).
Идеального клона не будет: без каталогов Spotify и Яндекса часть импортированных треков
не найдётся.
